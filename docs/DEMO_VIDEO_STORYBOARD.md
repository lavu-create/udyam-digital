## Recording Checklist & Technical Setup

1. **Resolution:** 1920x1080 (1080p, 16:9 widescreen).
2. **Viewport Size:** Clean browser window set to 1280x800 or full HD zoom 100%.
3. **Active URL:** Open `http://localhost:8000`.
4. **Microphone:** Clean, noise-cancelled vocal track.
5. **Pacing:** Crisp, deliberate cursor movements; pause 1 second after each action to let visual feedback register.
